# ระบบกรอกข้อมูลใบสมัคร ม.4 ประเภท ม.3 โรงเรียนเดิม · โรงเรียนดัดดรุณี

หน้าเว็บ (GitHub Pages) สำหรับคณะกรรมการรับนักเรียน
ข้อมูลทั้งหมดอยู่ใน Google Sheets ของโรงเรียน หน้าเว็บนี้ไม่มีข้อมูลนักเรียน และต้องเข้าสู่ระบบด้วยชื่อครู + PIN

ตั้งค่า: แก้บรรทัด `const API = "..."` ใน `index.html` เป็นลิงก์เว็บแอป Apps Script (ลงท้าย `/exec`)
